# ملخص الإصدار 2.1.0

يركز الإصدار **2.1.0** من `chromium-web-embed` على جعل مساحة Chrome المُدارة أوضح للمستخدم، وأقوى للمطور، وأكثر قابلية للضبط عند استخدامها مع وكلاء الذكاء الاصطناعي. يظل نطاق المكتبة ثابتًا: إنها تتحكم فقط في تبويبات المجموعة التي ينشئها التطبيق في Chrome المحلي للمستخدم، ولا تمنح وصولًا إلى تبويباته الأخرى أو نظام التشغيل أو بيانات الاعتماد.

| المجال | ما أضيف أو حُسن |
| --- | --- |
| هوية الإضافة | أيقونات PNG مشتقة من صورة المستخدم بالأحجام 16 و32 و48 و128، ضمن manifest وحزمة التنزيل. |
| إدارة المساحة | تسمية المساحة، وتثبيت وكتم ونسخ تبويباتها، ولقطة وصفية لحالتها عبر `workspaceSnapshot()`. |
| واجهة الوكيل | دوال `open()` و`navigate()` و`reload()` و`snapshot()` ضمن `ManagedBrowserAgent`، مع بقاء موافقة المستخدم شرطًا للتنفيذ. |
| تجربة الإضافة | مؤشر حي لحالة تحكم الوكيل وملخص للخصوصية والمساحة في نافذة الإضافة. |
| التوثيق | أدلة JavaScript وReact وتنسيق الخادم ووكلاء الذكاء الاصطناعي، إضافة إلى نموذج مرجعي منظم. |

## التحقق المنفذ

أجري الفحص محليًا على المصدر قبل النشر. مرّ فحص TypeScript، ونجحت اختبارات Vitest — بما فيها اختبارات الأيقونات وواجهات إدارة المساحة وواجهة الوكيل ووجود الأدلة والنموذج المرجعي — ثم بُنيت حزمة الإضافة وفُحص محتوى الحزمة بـ`npm pack --dry-run`. تحوي الحزمة الناتجة أيقونات الإضافة وملف ZIP القابل للتحميل والأنواع وملفات البناء.

كما رُقي موقع **متصفح موهو** إلى الاعتماد المضمن `chromium-web-embed-2.1.0.tgz`. مر فحص الأنواع و8 اختبارات للموقع والبناء الإنتاجي بنجاح.

## حالة النشر

أعطى مالك المشروع موافقة مسبقة وصريحة على دفع التحديث إلى المستودع العام `MOHOAI/chromium-web-embed`. لذلك سيُنشر هذا الإصدار بعد اكتمال الفحص النهائي، مع دفع الحزمة وملف تنزيل الإضافة وملفات التوثيق إلى الفرع الرئيسي.

> قبل استخدام الوكيل في منتج حقيقي، يجب أن تعرض الواجهة الموافقة، وتوفر زر إيقاف دائمًا، وتطلب تأكيدًا جديدًا قبل أي إرسال أو شراء أو حذف أو تعديل دائم.
