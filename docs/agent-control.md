# تحكم وكلاء الذكاء الاصطناعي

توفر المكتبة واجهة **ManagedBrowserAgent** لتطبيقات الذكاء الاصطناعي التي تحتاج إلى مشاهدة صفحة الويب، فتح تبويبات جديدة، التنقل، النقر، الكتابة، والعودة أو التقدم. تعمل كل عملية داخل مساحة المتصفح التي أنشأها التطبيق نفسه، ولا يمكن للوكيل عرض أو التحكم في تبويبات المستخدم العادية خارج تلك المساحة.

| القدرة | متاحة للوكيل | الحد المقصود |
|---|---:|---|
| التقاط لقطة للتبويب المُدار | نعم | تبويب ضمن مساحة التطبيق فقط |
| فتح أو إغلاق تبويب | نعم | ضمن مجموعة التطبيق فقط |
| النقر والتمرير والكتابة | نعم | عبر Chrome DevTools Protocol للتبويب المُدار فقط |
| قراءة أو التحكم في تبويبات المستخدم الأخرى | لا | محظورة عند مستوى عامل الإضافة |
| التحكم في سطح المكتب أو التطبيقات الأصلية | لا | يتطلب برنامجًا أصليًا منفصلًا وصلاحيات نظام تشغيل |

يتطلب تنفيذ أي أمر أن ينشئ التطبيق مساحة عمل مع `agentControl: true`، أو يفعّل المستخدم خيار الوكيل لاحقًا باستخدام `client.setAgentControl(true)`. يمكن للمستخدم إيقاف هذا الخيار، أو إغلاق مساحة المتصفح؛ وعندها ترفض الإضافة كل الأوامر اللاحقة للوكيل.

```ts
import { createManagedBrowserAgent, createRealBrowserClient } from "chromium-web-embed";

const client = createRealBrowserClient();
await client.waitForExtension();
await client.createWorkspace({ url: "https://example.com", agentControl: true });

const agent = createManagedBrowserAgent({ client });
const screen = await agent.observe();
await agent.click(220, 180, screen.tabId);
await agent.type("بحث", screen.tabId);
```

> لا تحوّل هذه الإضافة Chrome إلى وكيل يتحكم في جهاز المستخدم بالكامل. هي جسر متصفح محدود، مرئي للمستخدم، ومعزول لكل تطبيق ويب.
