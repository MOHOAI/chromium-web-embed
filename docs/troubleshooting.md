# دليل الأخطاء الشائعة واستكشاف الأعطال

يشرح هذا الدليل الحالات الأكثر ظهورًا عند دمج `chromium-web-embed` مع إضافة **Moho Browser Workspace**. ابدأ دائمًا بالتأكد من رقم الإضافة الظاهر في `chrome://extensions` ومن أن موقعك أعيد تحميله بعد تثبيت الإصدار نفسه. لا يمكن للتطبيق اكتشاف إضافة لم يحمّل Chrome جسرها بعد، ولا يمكنه الوصول إلى تبويبات لم ينشئها داخل مساحته المعزولة.

> القاعدة الأساسية: اتصل بالإضافة، ثم استعلم عن المساحة، ثم أنشئها عند عدم وجودها، وبعد ذلك فقط اعرض التبويبات أو أرسل أوامر التحكم.

| العرض | السبب المعتاد | الحل المباشر | ما يجب فحصه |
| --- | --- | --- | --- |
| `bridge-not-detected` | الإضافة غير مثبّتة أو معطّلة أو لم يُعاد تحميل الموقع | فعّل الإضافة، أعد تحميل الموقع ثم نفّذ `waitForExtension()` | `chrome://extensions` وحالة `getConnectionDiagnostic()` |
| `No managed browser workspace exists` | طلب التطبيق قائمة تبويبات قبل إنشاء مساحة | نفّذ `workspace()`، ثم `createWorkspace()` عند عودة `null` | تسلسل التهيئة في التطبيق |
| `reconnect-required` | انقطع جسر Chrome أثناء أمر يغيّر الحالة | نفّذ `reconnect()` ثم أعد الأمر صراحةً بعد إعلام المستخدم | لا تعِد النقر أو الكتابة تلقائيًا |
| الكتابة تعمل ولا يعمل الحذف | العنصر المستهدف لم يأخذ التركيز أو التطبيق أرسل نصًا بدل مفتاح | انقر العارض، ثم استخدم `press("Backspace")` أو `clear()` | التركيز، وترتيب `keydown` و`keyup` |
| لا تظهر لقطة أو تظهر قديمة | العارض متوقف أو التبويب غير نشط أو الالتقاط معلق | استخدم `viewer.start()` وتابع `getMetrics()` | `framesRendered` و`lastCaptureMs` |
| تظهر صفحة الموقع بخطأ `Invalid URL` | عنوان تبويب مؤقت أو فارغ وصل من Chrome | اعرض العنوان كنص فقط ولا تنشئ `URL` إلا بعد التحقق | `normalizeTabUrl()` ومعالجة العنوان الفارغ |
| الوكيل يرفض الأمر | لم يمنح المستخدم موافقته أو أوقف التحكم | اطلب تفعيلًا ظاهرًا عبر `setAgentControl(true)` | حالة موافقة الوكيل داخل التطبيق والإضافة |
| لا يتم تحميل الإضافة من ملف ZIP | Chrome لا يثبت ZIP محليًا مباشرة | فك الضغط ثم استخدم «تحميل بدون حزمة» | وضع المطور ومسار المجلد المفكوك |

## تهيئة أول استخدام صحيحة

```ts
const browser = createRealBrowserClient();
await browser.waitForExtension({ timeoutMs: 8_000 });

let { workspace } = await browser.workspace();
if (!workspace) {
  ({ workspace } = await browser.createWorkspace({
    label: "مساحة تطبيقي",
    url: "https://example.com",
  }));
}

const tabs = await browser.listWorkspaceTabs();
```

لا تفترض أن مساحة سابقة ستبقى موجودة؛ قد يغلق المستخدم المجموعة أو يعيد تشغيل Chrome. الاستعلام الأولي عن `workspace()` آمن ويعيد `null` عند أول تشغيل، أما `listWorkspaceTabs()` فيتطلب مساحة موجودة.

## الإدخال: كتابة، حذف، اختصارات، وتركيب نص عربي

يعطي `SharedTabViewer` الحاوية تركيزًا عند الضغط بالمؤشر. لذلك ينبغي ألا تلتقط طبقة واجهة فوق العارض أحداث لوحة المفاتيح. يرسل العارض النص المركب بعد `compositionend`، وهي خطوة مهمة للغات التي تستخدم محرر إدخال أو تشكيلًا؛ بينما يرسل الحذف والاختصارات كمفاتيح CDP مستقلة.

| الحاجة | واجهة موصى بها | ملاحظة |
| --- | --- | --- |
| إدخال نص | `agent.type("نص")` أو لصق المستخدم | مناسب للنص المركب والعربية |
| حذف حرف | `agent.press("Backspace", { code: "Backspace" })` | يتطلب أن يكون الحقل المركز هو الهدف |
| مسح حقل | `await agent.clear()` | يرسل تحديد الكل ثم حذفًا |
| اختصار محفوظ | `agent.press("s", { code: "KeyS", modifiers: 2 })` | `2` يمثل Ctrl في بروتوكول CDP |
| لصق | حدث `paste` داخل العارض | يرسل النص العادي فقط، لا HTML أو ملفات |

إذا لم يعمل الإدخال، اختبر أولًا بالنقر داخل العارض، ثم جرّب مفتاحًا ظاهرًا مثل `Tab` أو `Backspace`. لا تستخدم إعادة محاولة تلقائية لأوامر تغير صفحة أو نموذجًا؛ فقد تؤدي إلى إرسال مزدوج.

## التعافي من انقطاع الاتصال

تتعافى **أوامر القراءة** مثل فحص الحالة ولقطة المساحة بإعادة اتصال محدودة، لأن تكرارها لا يغير حالة المستخدم. أما أوامر الفتح والتنقل والكتابة والنقر والتمرير فلا تتكرر تلقائيًا. عند فشل أحدها يظهر تشخيص `reconnect-required` كي يقرر تطبيقك، والمستخدم إن لزم، أن إعادة التنفيذ آمنة.

```ts
try {
  await agent.type("بحث");
} catch (error) {
  if (browser.getConnectionDiagnostic().code === "reconnect-required") {
    await browser.reconnect();
    // أظهر للمستخدم العملية التي لم تُنفذ واطلب منه تأكيد إعادتها.
  }
  throw error;
}
```

## تقرير تشخيص مفيد عند فتح بلاغ

أرفق رقم إصدار المكتبة والإضافة، متصفحك ونظام التشغيل، ناتج `browser.getConnectionDiagnostic()`، الخطوات التي تؤدي إلى العطل، ورسالة الخطأ الكاملة بعد إزالة أي بيانات حساسة. لا ترسل كلمات مرور أو ملفات تعريف ارتباط أو محتوى نماذج خاص؛ لا تحتاج المكتبة أيًا منها لتشخيص جسرها.
