# تشخيص نافذة إضافة Chrome

تظهر نافذة الإضافة فوق تبويب **تطبيق الويب** الحالي فقط؛ ولا تستخدم لاختيار تبويب للمشاركة. وظيفتها فحص جسر الاتصال وعرض حالة مساحة المتصفح التي أنشأها التطبيق.

| الرسالة في النافذة | معناها | الإجراء المطلوب |
| --- | --- | --- |
| `جسر الاتصال جاهز` | الصفحة تستخدم HTTP أو HTTPS وقد جهّزت الإضافة قناة الاتصال. | ارجع إلى التطبيق وأنشئ أو افتح مساحة المتصفح منه. |
| `افتح الإضافة من صفحة تطبيق ويب عادية باستخدام HTTP أو HTTPS` | فُتحت النافذة فوق `chrome://` أو صفحة ملف أو صفحة لا يسمح Chrome بالحقن فيها. | انتقل إلى موقع التطبيق وافتح النافذة مرة أخرى. |
| `هذه الصفحة خارج النطاق المسموح للإضافة` | لا تملك الإضافة صلاحية الوصول إلى أصل الصفحة. | أعد تحميل الإضافة بعد تحديث نطاقاتها أو استخدم تطبيقًا على HTTP/HTTPS. |
| `حُقن الجسر ولكن لم تظهر إشارة الجاهزية` | حُقن ملف الجسر بعد تحميل الصفحة أو منع سياق الصفحة الإشارة الأولى. | حدّث صفحة التطبيق ثم أعد الفحص. |
| `بانتظار الموقع لإنشاء مساحة متصفح` | الجسر يعمل لكن التطبيق لم يطلب إنشاء مجموعة التبويبات بعد. | اضغط زر البدء داخل التطبيق. |
| `المساحة المتصلة جاهزة` | توجد مجموعة تبويبات معزولة تخص أصل التطبيق الحالي. | يمكن عرض حالتها أو إغلاقها من النافذة، مع بقاء التحكم من داخل التطبيق. |

> لا تكشف النافذة تبويبات المستخدم المفتوحة، ولا تمنح التطبيق الوصول إلى سطح المكتب أو التطبيقات الأصلية. ترتبط كل مساحة بأصل تطبيق الويب الذي أنشأها فقط.
