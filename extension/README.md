# Real Browser Web Bridge extension

This is the load-unpacked Manifest V3 extension generated by the package build. Before installing it, replace the `content_scripts.matches` patterns in `manifest.json` with the exact origins of the web applications you trust, such as `https://app.example.com/*`.

Open `chrome://extensions`, enable Developer mode, select **Load unpacked**, and choose this `extension` directory. Do not add broad patterns such as `https://*/*`: every listed origin can ask the extension to control the user's Chrome tabs.
