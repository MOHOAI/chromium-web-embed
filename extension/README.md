# Moho Browser Workspace extension

This is the load-unpacked Manifest V3 extension generated by the package build. Download `real-browser-web-bridge-extension.zip` from the repository's `extension-download/` directory, unpack it in a stable local folder, and load that unpacked folder in Chrome. Chrome does not permit one-click web installation of an extension that is not published through the Chrome Web Store.

For production distribution, restrict `content_scripts.matches`, `host_permissions`, and `externally_connectable.matches` in `manifest.json` to the exact web-app origins you trust, such as `https://app.example.com/*`. The distributable package includes HTTP(S) sites so it also works on local and preview environments.

Open `chrome://extensions`, enable **Developer mode**, select **Load unpacked**, and choose the extracted `extension` directory. Reload the web application after enabling the extension. The application creates its own isolated Chrome tab group automatically; you do not select or share any pre-existing tab from the extension popup. The app may only control tabs created in its own origin-scoped workspace, and agent operations remain blocked until the user enables agent control within that workspace.
