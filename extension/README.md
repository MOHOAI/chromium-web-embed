# Real Browser Web Bridge extension

This is the load-unpacked Manifest V3 extension generated by the package build. Download `real-browser-web-bridge-extension.zip` from the repository's `extension-download/` directory, unpack it in a stable local folder, and load that unpacked folder in Chrome. Chrome does not permit one-click web installation of an extension that is not published through the Chrome Web Store.

Before installing it, replace the `content_scripts.matches` patterns in `manifest.json` with the exact origins of the web applications you trust, such as `https://app.example.com/*`. The bundled sample allows local development and Manus preview origins only.

Open `chrome://extensions`, enable Developer mode, select **Load unpacked**, and choose this `extension` directory. Then click the extension icon and choose one HTTP or HTTPS tab to share. The page can request screenshots and input only for that user-selected tab; it cannot select a tab silently. Do not add broad patterns such as `https://*/*`: every listed origin can ask the extension to control the user's Chrome tabs.
