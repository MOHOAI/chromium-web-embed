# Moho Browser Workspace Extension (v4.0.0)

إضافة متصفح Chrome/Chromium مبنية بنظام **Manifest V3** توفر جسرًا معزولًا لتشغيل مساحات العمل وتنفيذ أوامر وكلاء الذكاء الاصطناعي (Gemini Computer Use، Anthropic Claude، OpenAI Responses API، وغيرها) عبر Chrome DevTools Protocol (`chrome.debugger`).

## التثبيت في Chrome
1. افتح `chrome://extensions` في متصفح Chrome أو Edge أو Brave.
2. فعّل **وضع المطور (Developer mode)**.
3. اضغط على **تحميل إضافة غير مضغوطة (Load unpacked)** واختر مجلد `extension/` (أو فك ضغط `extension-download/real-browser-web-bridge-extension.zip`).
