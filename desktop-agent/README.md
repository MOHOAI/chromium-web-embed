# Moho Windows 10/11 Desktop Agent (`v5.0.0`)

وسيط محلي خفيف مخصص لنظام **Windows 10 و Windows 11 فقط** يربط إضافة **Moho Browser Workspace** (وتطبيقات الذكاء الاصطناعي المتصلة بها مثل MOHO و Gemini و Claude و ChatGPT) بسطح مكتب افتراضي جديد وفارغ مع بث مباشر للشاشة وتحكم كامل بالماوس ولوحة المفاتيح.

## التثبيت والتشغيل السريع (Windows 10 / 11)

1. تأكد من تثبيت **Python 3.10+** على ويندوز.
2. انقر مرتين على **`start_agent.bat`** (أو شغّل `powershell -ExecutionPolicy Bypass -File install_windows.ps1` لأول مرة).
3. سيعمل الوسيط محليًا فقط على `ws://127.0.0.1:47892` وسيطبع **Auth Token** عشوائي.
4. الصق التوكن في نافذة الإضافة (`Moho Browser Workspace`) أو في تطبيق الويب واضغط **اتصال**.
   - للتجربة المحلية السريعة بدون توكن، يمكنك تشغيل: `start_agent.bat --no-auth`

## الأمان
- يرتبط الوسيط بعنوان `127.0.0.1` فقط (لا يمكن الوصول إليه من الشبكة الخارجية).
- يدعم **زر إيقاف طارئ (Emergency Stop)** يوقف فورًا كل النقرات والبث المباشر.
